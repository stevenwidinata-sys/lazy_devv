# Lazy Dev

One prompt. Every AI.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run test
npm run build
```

## Deploy to Vercel

1. Push `main` to GitHub.
2. Import `stevenwidinata-sys/lazy_devv` at [Vercel](https://vercel.com/new).
3. Vercel detects Vite. Keep build command `npm run build` and output directory `dist`.
4. Deploy.

No environment variables or backend needed.
